# pickjwt

Pick URLs and jwt query parts with stable normalization.

**Site:** https://theworker02.github.io/pickjwt/

## Install / run

```bash
git clone https://github.com/theworker02/pickjwt.git
cd pickjwt
node src/cli.js
node --test
```
